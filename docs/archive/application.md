プロジェクト名：育てる地図（仮）私たちは、訪れた場所、移動経路、滞在の仕方、場所を選ぶ理由といった行動パターンを、その人固有のパーソナルな特徴として蓄積する地図を提案する。既存の地図では、場所そのものの情報は分かっても、「その人が街をどう使い、なぜそこを選ぶのか」という行動の文脈は残りにくい。その結果、地域住民が持つ暗黙知や埋もれた魅力が他者や観光客に伝わりにくく、地域への理解や回遊にもつながりにくい。本サービスでは、日々の行動やAIとの会話から行動パターンを分析・分類し、「寄り道型」「探索型」「静かな場所を好む」など、その人らしい街との関わり方を地図上に可視化する。使うほど地図が自分らしく育ち、その日の気分や状況に合った場所やルートの推薦にも活用される。また、友人や地域住民との行動パターンの共通点や違いを発見したり、似た行動傾向を持つ人が好む場所を探したり、他者の視点に切り替えて街を追体験したりできる。単なる場所共有ではなく、「自分とこの人は意外と街の歩き方が似ている」といった同一性や差異そのものを楽しみながら、相互理解と地域の新しい魅力発見につなげる。将来的には店舗や行政からの地域情報も重ね、観光・地域回遊から工事、豪雨、浸水、避難場所などの公共情報まで、人と地域の知識が継続的に蓄積される地図を目指す。
