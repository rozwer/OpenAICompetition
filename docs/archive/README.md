# アーカイブ

ここには、現在の実装判断の基準から外した文書を、検討経緯として保管しています。
実装時は[現在の仕様と資料](../README.md)を参照してください。

| 文書 | 保管理由 | 現在の参照先 |
|---|---|---|
| [要件定義・技術設計 v3](requirements-v3.md) | v4と詳細仕様書で更新された旧設計。現在とは異なる画面構成や前提を含む | [基礎要件 v4](../spec/requirements.md)、[実装仕様書](../spec/implementation.md) |
| [v3レビュー](v3-review-2026-09-05.md) | v3を対象にした2026年9月5日のレビュー。現行仕様の未解決課題一覧としては扱わない | [実装仕様書](../spec/implementation.md)、[受入条件](../spec/acceptance-criteria.md) |
| [応募時の原文](application.md) | 提出時点の構想を保存する記録。後続のすり合わせで変更された考え方を含む | [基礎要件 v4](../spec/requirements.md) |

文書の本文は当時の記録として保持し、移動に伴うリンクだけを更新します。
新たな採用判断や仕様変更は、現在の仕様書へ記録します。
