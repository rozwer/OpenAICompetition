# みんなの地図 MVP

2026-09-08。提供されたGUI素材を参照し、4画面のサンプル体験を実装。

- 入口: 下部「つながる」または地図メニュー「みんなの地図」。共通の4項目ナビは維持。
- ホーム: Kaito/Yuki/Ryo/Minaの地図カード、名前・エリア・好み検索。実際の友人招待は開閉欄に既存機能を保持。
- 友人の地図: サンプルの地点をMapLibreで表示。レンズを切り替えると「あなた」のサンプル訪問先になる。場所一覧と地図のピンから詳細へ。
- 比較: 共通・自分のみ・相手のみ、エリア切替。重なり度は訪問先集合の共通数/和集合数で計算。心理的相性ではない。記録0件は0%と空表示。
- 同じ場所: 二人の回数、平均滞在、context、meaningを並置。未訪問側は記録なし。
- AI比較: ボタン操作時だけローカルCodexへ固定サンプル集計を送る。構造化JSONの検証、セッション・同一オリジン・既知ID限定・同時2件・30秒制限。失敗はエラー表示。自動の数値比較はAI生成と呼ばない。

## データと分離
contracts/everyone.tsが表示用の契約、domain/everyone.tsが集合比較、fixtures/everyone.tsが明示的な架空データ。appがfeatureへ注入する。友人featureから他featureへのimportなし。

素材の画像はモックの切り出しであり、実店舗写真・実測地図ではない。画面上で人物/訪問/意味づけ/写真がサンプルと明示。メイン地図は既存ローカルOSM道路/水面とサンプル座標で描画する。

実ユーザーの訪問履歴・会話・個人解釈は取得/共有しない。「あなた」側もサンプル。実ユーザー比較には、共有範囲・同意・撤回の契約と共有用の集計APIを追加してfixture注入を置換する。招待承認だけでは非公開データを公開しない。

今回未実装: 2人の経路提案への連携、共有地図への保存、公開設定、実記録から友人プロフィールを生成する処理。既存の実データDBは変更しない。

検証: 集合比較と空集合の単体検証、4画面遷移/検索/レンズ/エリア/比較フィルター/場所詳細/AI応答表示のE2E、API拒否ケース。AI画面E2Eはモック応答を使用。

確認結果: pnpm check（49件成功）、pnpm build成功。対象E2E 4件成功。稼働サーバーで実際のローカルCodex比較を1回実行し、HTTP 200とcommon/difference/discoveryの構造化応答を確認した。送信は固定サンプルのみ。
