# 最初の実装版の検証記録

環境：Windows、Node.js 24.14.1、pnpm 10.33.0、Next.js 16.3.4、プロジェクト内Codex CLI 0.153.4。
これは全7機能の受入完了記録ではない。

| 確認 | 結果 |
|---|---|
| `pnpm check:boundaries` | 合格。機能間import、機能→DB/Codex直接参照、内側→外側依存を検出する |
| TypeScript | 合格 |
| `pnpm test` | 通常7件合格。実AIテストは既定でスキップして利用枠を消費しない |
| `RUN_CODEX_LIVE=1`で実AIテスト | 1件合格。架空の好みへの日本語応答と本人発言の抽出を確認 |
| `pnpm build` | 合格 |
| `pnpm test:e2e` | 3件合格。本番ビルド、独立DB、Chromeで実行 |
| 地図の目視 | 建物・道路・マーカー・保存済み軌跡を確認 |

通常テストは欠落区間、精度不明、異常速度、20mの境界、建物の辺の中間への接近、記録重複、所有者分離、申請承認権限、AI失敗からの再試行、訂正競合を確認する。
E2Eは位置再生の保存、A/B独立セッションの招待・承認、未認証・異なるOriginからの拒否、390×844の入力と横はみ出しを確認する。

発見・修正した問題：

- MapLibreのCSSにより地図の高さが失われたため、コンテナの位置・サイズ指定を修正。
- 古いグローバルCodex CLI 0.140.0は既定モデルと非互換。プロジェクト内0.153.4に固定し、実AIテストが成功。
- サーバーインスタンス初期化時に進行中メッセージを解除しないよう、期限付きのDB上の処理取得へ変更。
- E2Eが開発用DBを変更しないよう、毎回独立したDBで本番サーバーを起動する構成へ変更。

未検証：実iPhone、Androidエミュレーター、Mac、実GPS取得、長時間の負荷、全7機能の通しデモ、4人で4時間の再現。
SQLiteはNodeの実験的API警告が出る。DBアダプターを差替え可能にしており、Supabaseは未接続。
