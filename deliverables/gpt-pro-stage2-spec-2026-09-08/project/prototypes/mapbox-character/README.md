# Mapbox 人物・ランドマーク確認用プロトタイプ

Mapbox Standardのカラー3Dランドマークと、George Blackwellの人物モデルを同じ画面で確認するための小さな試作です。

## 起動

```bash
cp .env.example .env.local
# .env.local の VITE_MAPBOX_ACCESS_TOKEN にMapboxの公開トークンを設定
bun install
bun run dev
```

東京、横浜、名古屋、箱根、大阪を切り替え、Mapbox標準3D表現の地域差と人物の視認性を確認できます。人物にはGLB内の`Walk`アニメーションを使用します。

## 表示と操作

人物は地図上で動きと輪郭を確認できるよう、実寸より大きな確認用サイズで表示します。これは最終仕様の縮尺ではありません。Mapbox Standardは`default`テーマを使い、通常表示は3Dです。ズーム17.3未満で通常ビル、16.4未満でランドマークと人物を順に外して2D俯瞰へ移行します。3Dファサード、3D樹木、一般POIラベル、歩行者道路は常に無効です。

## 描画負荷の調整

人物は64×112pxの小型WebGLキャンバスへ最大12fpsで描画し、Mapboxの座標マーカーとして配置します。全画面の人物用キャンバスを廃止したため、地図操作中も人物位置はMapboxと同じ更新で追従します。地図操作中は人物アニメーションを一時停止し、Mapboxの描画と負荷が重ならないようにしています。Mapboxのワーカーは1本、タイルキャッシュは最大12枚に制限しています。地図はズーム16.1未満へ引けず、選択地域から大きく離れて移動できません。

Mapbox本体は表示領域の80%の内部解像度で描画して画面全体へ拡大します。地図キャンバスの画素数を36%抑える代わりに、細い文字や線は等倍描画よりわずかに柔らかく見えます。

3Dランドマークを読み込んだ場合も、方向光の影生成は無効です。環境光と影を落とさない方向光だけを使い、形状の判別に必要な明暗を残します。

## 人物モデルの再変換

元のBlenderメッシュは`Mirror`モディファイアで左右を構成しています。再変換するときは、片側だけのGLBを作らないよう`Mirror`を適用してからArmatureとアニメーションを書き出す`./scripts/export_basic_human.py`を使います。`python3 ./scripts/validate_basic_human.py`で、左右の境界、`Idle`・`Run`・`Walk`、スキンを確認できます。

## 2026-09-08の表示確認

| 地域 | Mapbox Standardの確認結果 |
|---|---|
| 東京駅・丸の内 | 高。駅舎と周辺高層棟の形状・ファサードが見える |
| 横浜・山下公園 | 中。マリンタワーと氷川丸を識別でき、周辺街区は汎用形状が中心 |
| 名古屋・栄 | 高。中部電力 MIRAI TOWERとオアシス21を識別できる |
| 箱根・芦ノ湖 | 低。湖岸と建物形状は見えるが、象徴的な3Dランドマークが不足 |
| 大阪・道頓堀 | 低〜中。街区形状は見えるが、道頓堀らしい象徴物は補完候補 |

確認結果は表示時点のMapboxデータとカメラ位置に基づく目視評価です。公開されている都市別の網羅率ではありません。

## 依存関係と認証

- Mapbox GL JS 3.30.0
- Three.js 0.180.0
- Vite 7.3.6

ブラウザには`pk.`で始まる公開トークンだけを渡します。`.env.local`はリポジトリの`.gitignore`対象です。Mapboxロゴと帰属表示はMapbox GL JSの標準コントロールをそのまま表示します。

人物モデルの出典は[帰属表示](public/models/basic-human/ATTRIBUTION.md)、提出用の開示案は[第三者コンポーネント一覧](THIRD_PARTY_NOTICES.md)を参照してください。
