# 育てる地図

訪問と対話から、自分にとっての場所の意味を残す地図アプリです。通うほど街が育ち、友人の体験や目的に合うルートを見つけ、プラグインで機能を増やします。

現在は要件と詳細設計を整備し、[地図・人物のプロトタイプ](prototypes/mapbox-character/README.md)で表示を確認しています。アプリ全体の実装・通し検証とは区別します。最初の完成地点はMacの仮想端末でのデモ、スマホ実機への導入は追加段階です。

利用体験は最新のタブ別要件を優先します。既存の詳細仕様・API・55の受入条件には未反映の追加要件があるため、実装前に対応するタブ要件と照合してください。仕様書の起動・検証コマンドは実装予定の契約であり、試作の起動手順とは別です。

共通用語は[用語集](CONTEXT.md)、旧設計と応募原文は[アーカイブ](docs/archive/README.md)にあります。APIキーなどの資格情報はGit管理外の`.env`や`.local/`に保存します。
